Gemini 3.6 Flash summarises your session into four fields — context, insight, location, next step.

🔒 Sensitive data excluded

Gmail, banking, social feeds, password managers and auth pages never reach the AI layer.

🛡️ Never an empty screen

Deterministic fallback guarantees a useful summary even if the AI call fails.

🔄 Session intent check

Away for hours? WhereWasI asks: Resume, Start fresh, or Maybe later.

🧱 Injection protection

Page titles and URLs are treated as untrusted data. Injected instructions are silently ignored.

Try the beta

Install directly from GitHub — no Chrome Web Store required

📦 Load the unpacked extension

  1. Clone the repo: git clone https://github.com/ammu1seenu-lab/wherewasai
  2. Open Chrome and go to chrome://extensions
  3. Enable Developer mode (toggle, top right)
  4. Click Load unpacked and select the cloned folder
  5. Pin the WhereWasI icon to your toolbar
  6. Click the icon and hit Start capturing
